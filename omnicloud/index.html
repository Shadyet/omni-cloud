Firebase One-Time Setup

Why Firebase?
Firebase handles Google & Microsoft OAuth for you — no registering apps, no copying Client IDs. It's free and takes about 3 minutes to set up once.
  1. Go to console.firebase.google.com → Create project
  2. Click Add app → choose Web (</>)
  3. Copy the firebaseConfig object shown
  4. In Authentication → Sign-in method, enable Google and/or Microsoft
  5. Add http://localhost:8080 to Authorized domains
